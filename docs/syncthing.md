# Guía de entrega y sincronización con Syncthing

> Esta guía se completará en la Fase 7 del proyecto.

## Principios clave
- PC de origen: Carpeta configurada como "Solo enviar" (Send Only).
- Dispositivo móvil (celular): Carpeta configurada como "Solo recibir" (Receive Only).
- La aplicación local no gestiona Syncthing por código; Syncthing corre como proceso independiente en el sistema operativo.
